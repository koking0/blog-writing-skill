# 博客写作检查清单

## 文章骨架

```markdown
# 清晰、准确、含主关键词的标题

> 一句话说明读者、问题和收益。

## 引言
快速交代背景、读者痛点、本文能解决什么，以及必要的范围/日期说明。

## 主体
按问题或任务拆成 H2；每节先给结论，再给解释、步骤、案例或证据。

## 常见问题（可选）
只放真实且尚未在正文中充分回答的问题。

## 结语
总结关键动作，给出下一步，而不是重复整篇文章。

## 参考资料
列出原文、数据、工具和外部图片来源。
```

## 写作自检

- [ ] 目标读者、文章类型和读者行动明确
- [ ] 标题准确且包含自然的主关键词
- [ ] 引言在前几段说明价值
- [ ] H2/H3 层级、段落长度和列表适合扫读
- [ ] 事实、数据、版本和链接可核验
- [ ] 个人经验、作者观点和外部事实有清晰区分
- [ ] 先完成内容，再做关键词、语句和排版优化
- [ ] 结论不夸大，不把 SEO 指标当成真实排名

## SEO 交付字段（按需）

| 字段 | 写法 |
| --- | --- |
| 主关键词 | 一个最能代表搜索意图的词组 |
| 相关关键词 | 同义词、问题词、上下位词，少量即可 |
| Meta Title | 准确说明主题，避免堆词和标题党 |
| Meta Description | 在有限字数内说明内容与收益，不承诺正文没有的结果 |
| Slug | 简短、稳定、可读，包含核心词即可 |
| 标签/分类 | 选择能帮助站内组织内容的词，不要无限增加 |

## 翻译/改写自检

- [ ] 原文标题、作者、链接和来源许可已注明
- [ ] 中文不是逐句直译，原意、限制条件和语气没有被改掉
- [ ] 原文的个人经历或数据没有被冒充为译者经历
- [ ] 时效性内容有日期/版本或复核提示
- [ ] 引用、图片和外部链接的版权边界清楚

## 发布前后

- [ ] 目标平台字段已映射：分类、标签、摘要、文章类型、原文链接
- [ ] 图片已上传或使用稳定来源；每张有合适的 alt，必要时有 caption
- [ ] 预览检查移动端、代码块、表格、链接和图片加载
- [ ] 只有用户明确授权时才发布
- [ ] 发布后记录页面成功提示或文章 URL；“审核中”要如实说明
